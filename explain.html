README موسع جدًا لمشروع رادار الأقمار الصناعية

1. مقدمة

هذا المشروع عبارة عن نظام رادار أقمار صناعية تفاعلي، يتم عرضه على كرة أرضية ثلاثية الأبعاد باستخدام مكتبة CesiumJS. النظام يقوم بعرض الأقمار الصناعية النشطة على الكرة الأرضية، ويحسب مواقعها بدقة باستخدام مكتبة satellite.js من ملفات TLE، وهي اختصار لـ "Two-Line Element set".

ملف الـ TLE يحتوي على بيانات محددة لكل قمر: المدار، الارتفاع، الميل، وعدة قيم أخرى، مما يمكننا من حساب الموقع اللحظي للقمر في أي وقت.

عند الضغط على أي قمر، يظهر لوحة جانبية تحتوي على:

  • اسم القمر الصناعي.
  • ارتفاعه الحالي عن سطح الأرض بالكيلومترات.
  • المساحة التي يغطيها القمر على سطح الأرض (Footprint).
  • رسالة تحذيرية إذا كان القمر في مدار عالي جدًا.

النظام مصمم بشكل قابل للتوسع، بحيث يمكن إضافة:

  • موديلات ثلاثية الأبعاد بدل النقاط البسيطة.
  • طبقات بيانات إضافية مثل مسارات الأقمار أو المحطات الأرضية.
  • خيارات التحكم في الارتفاع، التكبير، وتحديث البيانات بشكل مستمر.

2. بيئة العمل والملفات المستخدمة

  • index.html: الملف الرئيسي الذي يحتوي على الكود بالكامل.
  • CesiumJS: مكتبة JavaScript مفتوحة المصدر لعرض الكرة الأرضية ثلاثية الأبعاد.
  • satellite.js: مكتبة JavaScript لحساب مواقع الأقمار من ملفات TLE.
  • ملف TLE: يتم جلبه من Celestrak، وهو قاعدة بيانات حية للأقمار النشطة.
  • HTML Elements: div#cesiumContainer لعرض الكرة الأرضية، وdiv#data-panel للوحة البيانات.

ملاحظة هامة: الكود يستخدم Async/Await لأن جلب البيانات من الإنترنت وتحميل التضاريس يحتاج وقتًا، ونحتاج انتظار النتائج قبل متابعة تنفيذ الكود.

3. createViewer()

هذه الفانكشن مسؤولة عن إنشاء مشهد Cesium الكامل، مع تحميل التضاريس العالمية، وإعداد المشهد للعرض والتحريك.

async function createViewer() {
  return new Cesium.Viewer('cesiumContainer', {
    shouldAnimate: true,
    terrainProvider: await Cesium.createWorldTerrainAsync()
  });
}

شرح كل سطر بالتفصيل

  • async function createViewer(): تعرف فانكشن غير متزامنة async لأننا سنقوم بعملية تحميل التضاريس asynchronously من الإنترنت.
  • return new Cesium.Viewer('cesiumContainer', { ... }): هنا ننشئ كائن Viewer جديد من Cesium.
    • 'cesiumContainer': هذا هو معرف العنصر HTML حيث ستتم عملية العرض.
    • كائن الإعدادات {...}:
      • shouldAnimate: true: يطلب من Viewer تحديث الحركة بشكل مستمر، أي أن أي تحديث في موقع الأقمار سيظهر مباشرة.
      • terrainProvider: await Cesium.createWorldTerrainAsync(): تحميل التضاريس العالمية بشكل غير متزامن.
        • Cesium توفر نموذج التضاريس العالمي لتجعل الكرة الأرضية تبدو ثلاثية الأبعاد وواقعية.
        • نستخدم await لأنه عملية التحميل تأخذ وقتًا ويجب انتظارها قبل إرجاع Viewer.

النقطة المهمة هنا: هذه الفانكشن ترجع الـ Viewer جاهز، يمكن استخدامه مباشرة في فانكشن startGlobalRadar لبقية العمليات مثل تحميل الأقمار، إنشاء footprint، وإعداد التفاعل.

4. loadSatellites(viewer)

هذه الفانكشن مسؤولة عن تحميل بيانات الأقمار الصناعية من الإنترنت، وتحويلها إلى كائنات Cesium تظهر على الكرة الأرضية.

async function loadSatellites(viewer) {
    const url = 'https://celestrak.org/NORAD/elements/gp.php?GROUP=active&FORMAT=tle';
    const response = await fetch(url);
    const data = await response.text();
    const lines = data.split('\n');

    for (let i = 0; i < lines.length - 3; i += 3) {
        const satRec = satellite.twoline2satrec(lines[i+1], lines[i+2]);
        viewer.entities.add({
            name: lines[i].trim(),
            customData: { satRec: satRec },
            position: new Cesium.CallbackProperty((time) => {
                const date = Cesium.JulianDate.toDate(time);
                const posVel = satellite.propagate(satRec, date);
                if (posVel.position) {
                    const gmst = satellite.gstime(date);
                    const posGd = satellite.eciToGeodetic(posVel.position, gmst);
                    return Cesium.Cartesian3.fromDegrees(
                        satellite.degreesLong(posGd.longitude),
                        satellite.degreesLat(posGd.latitude),
                        posGd.height * 1000
                    );
                }
            }, false),
            point: { pixelSize: 4, color: Cesium.Color.WHITE }
        });
    }
}

شرح كل سطر بالتفصيل

  • const url = ...: رابط قاعدة بيانات الأقمار الحية بصيغة TLE. كل قمر في قاعدة البيانات يحتوي على 3 أسطر:
    • السطر الأول: اسم القمر.
    • السطر الثاني والثالث: بيانات المدار (TLE).
  • const response = await fetch(url): نقوم بجلب الملف من الإنترنت. نستخدم await لأن الشبكة تحتاج وقتًا، ونريد الانتظار حتى يكتمل التحميل.
  • const data = await response.text(): نحول الاستجابة إلى نص خام.
  • const lines = data.split('\n'): نقسم النص إلى أسطر، لأن كل قمر لديه 3 أسطر.
  • الحلقة for (let i = 0; i < lines.length - 3; i += 3): - نبدأ من السطر الأول (i=0). - نزيد i بمقدار 3 كل مرة لأن كل قمر لديه 3 أسطر. - lines[i] اسم القمر، lines[i+1] و lines[i+2] بيانات المدار.
  • const satRec = satellite.twoline2satrec(lines[i+1], lines[i+2]): هنا نستخدم مكتبة satellite.js لتحويل السطرين الثاني والثالث إلى كائن satRec يحتوي على كل المعلومات اللازمة لحساب موقع القمر.
  • viewer.entities.add({ ... }): نضيف كائن جديد على الكرة الأرضية.
    • name: lines[i].trim(): اسم القمر.
    • customData: { satRec }: نخزن بيانات المدار داخل الكائن لأستخدامها لاحقًا.
    • position: new Cesium.CallbackProperty(...): - هذه الخاصية تحدد موقع الكائن على الكرة الأرضية بشكل ديناميكي. - CallbackProperty يتم استدعاؤها في كل فريم من رسوم Cesium.
    • point: { pixelSize: 4, color: Cesium.Color.WHITE }: يمثل القمر كنقطة بيضاء.

شرح الرياضيات والحسابات خطوة خطوة

  • const date = Cesium.JulianDate.toDate(time): - JulianDate هو نوع وقت يستخدمه Cesium. - نحولها إلى كائن Date عادي حتى تستطيع مكتبة satellite.js التعامل معها.
  • const posVel = satellite.propagate(satRec, date): - هذه الدالة تحسب **موقع وسرعة القمر في الوقت الحالي**. - الناتج يحتوي على إحداثيات **ECI (Earth-Centered Inertial)**، أي نظام إحداثيات مركزه مركز الأرض.
  • التحقق من if(posVel.position): نتأكد أن الحساب نجح.
  • const gmst = satellite.gstime(date): - GMST = Greenwich Mean Sidereal Time - نحتاجه لتحويل الإحداثيات من النظام ECI إلى النظام الجغرافي (Latitude, Longitude).
  • const posGd = satellite.eciToGeodetic(posVel.position, gmst): - نأخذ الإحداثيات الثلاثية ونحولها إلى **خط عرض وخط طول وارتفاع عن سطح الأرض**.
  • Cesium.Cartesian3.fromDegrees(...): - نحول خط الطول والعرض والارتفاع إلى إحداثيات XYZ في نظام Cesium لعرض القمر على الكرة.
  • تفسير خطوة خطوة للرياضيات:
    • ارتفاع القمر posGd.height بالمتر، نضرب ×1000 لتحويله إلى متر لأن Cesium يستخدم متر.
    • التحويل من ECI إلى Geodetic يعتمد على دوران الأرض (GMST).
    • هذه الطريقة تسمح للقمر بالتحرك بشكل صحيح على الكرة الأرضية في الوقت الحقيقي.

5. createFootprint(viewer)

الفانكشن دي مسؤولة عن إنشاء الدائرة الذهبية التي تمثل المساحة التي يغطيها القمر على سطح الأرض.

function createFootprint(viewer) {
    return viewer.entities.add({
        ellipse: {
            material: Cesium.Color.GOLD.withAlpha(0.2),
            outline: true,
            outlineColor: Cesium.Color.WHITE,
            height: 0
        },
        show: false
    });
}

شرح كل سطر بالتفصيل

  • viewer.entities.add({ ... }): نضيف كائن جديد على الكرة الأرضية.
  • ellipse: نوع الشكل الذي نرسمه، دائرة/إهليلج، هنا نصف قطره سيتغير ديناميكيًا حسب ارتفاع القمر.
  • material: Cesium.Color.GOLD.withAlpha(0.2): لون شفاف للدوائر الذهبية.
  • outline: true و outlineColor: Cesium.Color.WHITE: لجعل محيط الدائرة واضحًا.
  • height: 0: الدائرة على سطح الأرض (ارتفاع 0).
  • show: false: نخفي الدائرة أولًا، ونظهرها فقط عند الضغط على القمر.

6. setupClickHandler(viewer, footprint)

هذه الفانكشن مسؤولة عن:

  • تحديد القمر الذي ضغط المستخدم عليه.
  • تحديث لوحة البيانات الجانبية.
  • حساب نصف القطر والمساحة لكل قمر لحظة بلحظة.
function setupClickHandler(viewer, footprint) {
    const handler = new Cesium.ScreenSpaceEventHandler(viewer.scene.canvas);

    handler.setInputAction((click) => {
        const picked = viewer.scene.pick(click.position);

        if (Cesium.defined(picked) && picked.id && picked.id.customData) {
            const entity = picked.id;
            viewer.trackedEntity = entity;
            document.getElementById('data-panel').style.display = 'block';
            footprint.show = true;

            footprint.position = new Cesium.CallbackProperty((time) => {
                const pos = entity.position.getValue(time);
                if (!pos) return undefined;
                const carto = Cesium.Cartographic.fromCartesian(pos);
                return Cesium.Cartesian3.fromDegrees(
                    Cesium.Math.toDegrees(carto.longitude),
                    Cesium.Math.toDegrees(carto.latitude),
                    0
                );
            }, false);

            footprint.ellipse.semiMajorAxis = new Cesium.CallbackProperty((time) => {
                const pos = entity.position.getValue(time);
                if (!pos) return 0;
                const h = Cesium.Cartographic.fromCartesian(pos).height / 1000;

                // حساب الأفق البصري خطوة خطوة:
                let R = 6371; // نصف قطر الأرض بالكيلومتر
                // تخيل الأرض ككرة، القمر فوقها على ارتفاع h
                // المسافة الأفقية من القمر إلى الحافة التي يرى منها الأرض:
                let d = Math.sqrt(Math.pow(R + h, 2) - Math.pow(R, 2));

                // Spherical Cap Area: مساحة الجزء المرئي من الكرة الأرضية
                // هذا يشبه قطعة كعكة كروية من الكرة
                let area = 2 * Math.PI * R * R * (h / (R + h));

                // تطبيق حد أقصى للرسم لمنع "الدوائر الكبيرة جدًا"
                const maxVisualRadius = R * (Math.PI / 2) * 1000;
                let drawRadius = d * 1000;

                if (drawRadius > maxVisualRadius) {
                    drawRadius = maxVisualRadius;
                    document.getElementById('warning').style.display = 'block';
                } else {
                    document.getElementById('warning').style.display = 'none';
                }

                // تحديث لوحة البيانات
                document.getElementById('sat-name').innerText = entity.name;
                document.getElementById('sat-alt').innerText = Math.round(h).toLocaleString();
                document.getElementById('sat-area').innerText = Math.round(area).toLocaleString();

                return drawRadius;
            }, false);

            footprint.ellipse.semiMinorAxis = footprint.ellipse.semiMajorAxis;

        } else {
            footprint.show = false;
            viewer.trackedEntity = undefined;
            document.getElementById('data-panel').style.display = 'none';
        }
    }, Cesium.ScreenSpaceEventType.LEFT_CLICK);
}

شرح كل خطوة رياضي ومنطقي

  • الأفق البصري:
    • نعتبر الأرض كرة نصف قطرها R (6371 كم).
    • القمر على ارتفاع h كم فوق الأرض.
    • المسافة الأفقية d للقمر = الجذر التربيعي لـ [(R+h)² - R²]
    • تفسير مبسط: تخيل خط من القمر يصل لأقصى نقطة يمكن رؤيتها على سطح الأرض، يشكل مثلث قائم الزاوية مع مركز الأرض.
  • مساحة الجزء المرئي (Spherical Cap Area):
    • الفكرة: جزء الكرة الذي "يظهر" للقمر يشبه غطاء كروي.
    • المعادلة: area = 2 × π × R² × (h / (R+h))
    • الشرح: كلما ارتفع القمر، تزيد مساحة الجزء المرئي، لكن لا يمكن أن تتجاوز نصف مساحة الأرض.
  • التحكم بالرسم:
    • drawRadius يحدد نصف القطر الذي يظهر على الكرة.
    • maxVisualRadius يحد أقصى نصف القطر لمنع انفجار الرسم عند الأقمار العالية جدًا.
    • إذا تجاوز drawRadius الحد، نعرض تحذير #warning.
  • تحديث اللوحة: - كل فريم يحدث بيانات الارتفاع والمساحة، ويعرضها للمستخدم في الوقت الحقيقي.

7. استبدال النقاط بموديلات ثلاثية الأبعاد (3D Models)

حاليًا كل قمر يظهر كنقطة بيضاء بسيطة (point). يمكننا استبدالها بموديل ثلاثي الأبعاد ليكون العرض أكثر واقعية.

viewer.entities.add({
    name: "Satellite 1",
    customData: { satRec: satRec },
    position: new Cesium.CallbackProperty(...),
    model: {
        uri: 'models/satellite.glb',  // ملف النموذج ثلاثي الأبعاد بصيغة glTF
        minimumPixelSize: 64,         // الحجم الأدنى للنموذج على الشاشة
        maximumScale: 200,            // الحجم الأقصى للنموذج عند التكبير
        scale: 1.0,                    // مقياس افتراضي للنموذج
        color: Cesium.Color.WHITE
    }
});

شرح كل سطر

  • uri: رابط النموذج ثلاثي الأبعاد، يمكن أن يكون ملف .glb أو .gltf.
  • minimumPixelSize: يضمن أن النموذج لن يصبح صغيرًا جدًا عند عرض الكرة الأرضية من بعيد.
  • maximumScale: الحد الأعلى لتكبير النموذج لتجنب ظهور أحجام غير منطقية.
  • scale: مقياس النموذج الأساسي.
  • color: لون افتراضي، يمكن استخدامه لتظليل النموذج أو تمييزه عن الأقمار الأخرى.

الميزة: بهذه الطريقة يمكنك وضع أي نموذج، سواء كان قمر صناعي واقعي، صاروخ، أو حتى محطة فضاء.

8. التحكم في اتجاه القمر (Orientation)

عند استخدام موديلات 3D، يمكننا ضبط اتجاه القمر بحيث يتبع مسار مدار الأرض:

entity.model.orientation = new Cesium.VelocityOrientationProperty(entity.position);
  • Cesium.VelocityOrientationProperty: خاصية تجعل النموذج يتجه دائمًا في اتجاه الحركة (velocity) الخاص بالقمر.
  • مفيد لجعل الأقمار تظهر وكأنها تتحرك بشكل واقعي على المدار.

9. تحسين الأداء مع مئات الأقمار

إذا أردنا عرض مئات أو آلاف الأقمار، يجب اتباع النصائح التالية:

  • استخدم PointPrimitiveCollection بدلاً من Entities للنقاط البسيطة، فهو أسرع بكثير.
  • قم بتحديد disableDepthTestDistance للنقاط أو الموديلات لتقليل الحسابات الرسومية.
  • قلل استخدام CallbackProperty المعقدة لكل فريم إذا كان القمر بعيدًا عن الكاميرا.
  • قم بتحديث البيانات على فواصل زمنية محددة بدلاً من كل فريم (مثلاً كل ثانية).

10. نصائح Debugging

  • إذا لم يظهر القمر، تحقق من أن بيانات TLE صحيحة ويمكن الوصول إليها من الإنترنت.
  • استخدم console.log(entity.position.getValue(time)) لفحص المواقع لحظة بلحظة.
  • تأكد من أن Cesium.Ion.defaultAccessToken صالح إذا كنت تستخدم تضاريس Cesium Ion.
  • عند استخدام موديلات 3D، تحقق من المسار الصحيح للملف uri.
  • إذا كان الأداء بطيء، قلل عدد الأقمار أو استخدم clustering للـ Entities.

11. الخلاصة

هذا المشروع يشمل:

  • عرض الكرة الأرضية ثلاثية الأبعاد باستخدام CesiumJS.
  • تحميل بيانات الأقمار من ملفات TLE باستخدام satellite.js.
  • حساب المواقع اللحظية للأقمار وتحويلها من ECI → Geodetic → Cartesian3.
  • رسم الدائرة الذهبية (Footprint) لكل قمر وحساب المساحة المرئية (Spherical Cap Area) رياضيًا.
  • تفاعل مع المستخدم بالضغط على الأقمار، مع تحديث لوحة البيانات لحظيًا.
  • إمكانية استبدال النقاط بموديلات 3D حقيقية والتحكم في اتجاهها.
  • نصائح لتحسين الأداء عند عدد كبير من الأقمار وDebugging فعال.
